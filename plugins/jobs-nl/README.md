# Netherlands — a jobslop plugin

Job boards for the Netherlands: Jobbird.com. No key needed.

## What it adds

- **Job boards:** Jobbird (Dutch job board)
- **Suggested in the welcome tour for:** NL
- **Its own words in:** da, es, nl

## Install

It comes with jobslop: switch it on in the welcome tour or in **Settings → Plugins**.

To get a newer version before jobslop's next release, use **Check for plugin updates**, or paste `https://github.com/JobSlop/jobslop-plugin-jobs-nl` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
