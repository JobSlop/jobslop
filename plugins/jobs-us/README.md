# United States — a jobslop plugin

Job boards for the US: Jobs2Careers (a large job search) and USAJOBS (government jobs, needs a free key).

## What it adds

- **Job boards:** Jobs2Careers (Large US job search), USAJOBS (US government jobs)
- **Settings** (in its row in Settings → Plugins): USAJOBS API key, Email you registered with
- **Suggested in the welcome tour for:** US
- **Its own words in:** da, es, nl

## Install

It comes with jobslop: switch it on in the welcome tour or in **Settings → Plugins**.

To get a newer version before jobslop's next release, use **Check for plugin updates**, or paste `https://github.com/JobSlop/jobslop-plugin-jobs-us` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
