# United Kingdom — a jobslop plugin

Job boards for the UK: Reed.co.uk, one of the biggest (needs a free API key), and ZipRecruiter UK.

## What it adds

- **Job boards:** Reed (Big UK job board (needs a free key)), ZipRecruiter UK (ZipRecruiter's UK site)
- **Settings** (in its row in Settings → Plugins): Reed API key
- **Suggested in the welcome tour for:** GB
- **Its own words in:** da, es, nl

## Install

It comes with jobslop: switch it on in the welcome tour or in **Settings → Plugins**.

To get a newer version before jobslop's next release, use **Check for plugin updates**, or paste `https://github.com/JobSlop/jobslop-plugin-jobs-uk` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
