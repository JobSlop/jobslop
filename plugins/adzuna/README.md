# Adzuna — a jobslop plugin

Adzuna job search in 19 countries: the UK, US, Canada, Australia, much of Europe and more. Needs a free key.

## What it adds

- **Job boards:** Adzuna (Job search in many countries (needs a free key))
- **Settings** (in its row in Settings → Plugins): Adzuna App ID, Adzuna App Key
- **Suggested in the welcome tour for:** GB, US, CA, AU, NZ, DE, FR, NL, BE, ES, IT, AT, CH, PL, IN, SG, ZA, BR, MX
- **Its own words in:** da, es, nl

## Install

It comes with jobslop: switch it on in the welcome tour or in **Settings → Plugins**.

To get a newer version before jobslop's next release, use **Check for plugin updates**, or paste `https://github.com/JobSlop/jobslop-plugin-adzuna` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
