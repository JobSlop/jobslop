# My plugin for jobslop

What it adds to [jobslop](https://github.com/JobSlop/jobslop).

## Install

In jobslop: **Settings → Plugins → Install from link**, paste this repository's link, check what it adds, then **Install**.

## Making changes

See jobslop's plugin guide (`docs/PLUGINS.md` in the jobslop repository). Release a new version by raising
`version` in `plugin.json` and publishing a GitHub release tagged with it (e.g. `v0.2.0`).
